# Contributing to SynapseCitySOS

SynapseCitySOS is Apache-2.0 software maintained by VKU.VIC. Read `AGENTS.md`
for the public-tier dependency contract. Build with `npm ci && npm run build`,
run the unit tests, and keep emergency persistence and queueing in SynapseDX.
Use GitHub Issues for bugs and proposals. Pull requests must retain SPDX
headers, `NOTICE`, and a changelog entry for user-visible changes.
